공정도 선택

수정할 공정도와 등록된 작업본을 확인합니다. 공식 V1.0 파일은 읽기 전용입니다.

현재 로그인 사용자가 직접 등록한 파일만 표시됩니다. 다른 사용자의 작업본은 조회되지 않습니다.
VERIFIED 위치만 생성할 수 있습니다. 검토 필요·미지원 위치는 사유를 표시합니다.

업로드한 XLSX만 USER_WORKING_COPY로 등록합니다. 공식 V1.0 원본 바이트는 등록 거부되며, Profile이 작업본 SHA와 일치하지 않으면 생성할 수 없습니다. 신규 박스 추가는 BOX_ONLY TEST_ONLY입니다.

공정도·작업본을 선택하면 시트별 삽입 후보와 검증 상태를 표시합니다.

    로그인 후 공정도 목록을 불러옵니다.

    Profile 검증 필드 수정 (TEST_ONLY)
    현재 선택한 사용자 작업본의 exact-SHA Profile과 필드별 셀·값·서식을 서버가 다시 확인합니다. 공식 마스터·원본은 변경하지 않습니다.
    
    
    VERIFIED Profile 필드만 입력할 수 있습니다. 관리번호 변경, REVIEW_REQUIRED/UNSUPPORTED Profile, formula/병합/DrawingML 충돌은 차단됩니다. 실제 연결·유량은 수정하지 않습니다.
    
    
    
      
    
      
    
      
    
    
    
    
    공정·작업본·시트를 선택하면 Profile 버전, 증빙 수준, 작업본 SHA와 필드별 수정 가능 상태를 확인합니다.

    저장된 변경 제안 Before/After
    로그인한 사용자에게 연결된 제안과 저장된 합성 What-if 결과만 표시합니다. 결과가 없는 제안은 다운로드할 수 없습니다.
